# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to how they are expressed on this repo's GitHub issues.

| Label in mattpocock/skills | In our tracker                              | Meaning                                  |
| -------------------------- | ------------------------------------------- | ---------------------------------------- |
| `needs-triage`             | label `needs-triage`                        | Maintainer needs to evaluate this issue  |
| `needs-info`               | label `needs-info` (create if missing)      | Waiting on reporter for more information |
| `ready-for-agent`          | open issue without a triage label           | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | label `ready-for-human` (create if missing) | Requires human implementation            |
| `wontfix`                  | issue closed as "not planned"               | Will not be actioned                     |

When a skill mentions a role, use the corresponding GitHub state from this table.
