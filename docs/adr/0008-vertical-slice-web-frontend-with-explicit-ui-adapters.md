# Use a vertical-slice web frontend with explicit UI adapters

`apps/web` will be an authenticated operational workstation built as a TanStack Start application whose business source of truth stays in `apps/api`. The frontend will be organised by vertical slices around domain areas such as discharges, shifts, rotations, and reports; routing files will stay thin and compose those features instead of introducing a parallel global screens layer. Data access will be standardised through the Tuyau client and TanStack Query, with per-feature query keys, targeted invalidation, and optional route preloading that hydrates the same Query cache rather than creating a second fetching path. Each feature may adapt transport DTOs into UI-oriented view models at its boundary, including converting temporal strings into Luxon `DateTime` values, and may define separate form models when TanStack Form and Zod need shapes that differ from the screen model. Frontend state will stay disciplined: server state in TanStack Query, local screen state in component or form state, and only minimal cross-app client state for concerns such as authentication session or UI preferences; no business-wide client store should become a second source of truth. Shared frontend code will stay narrow and technical: `ui` for design-system primitives, `libraries` for tool integrations such as Tuyau, TanStack Query, TanStack Form, and authentication wiring, and `helpers` for small non-domain utilities; direct dependencies between business features should be avoided. UI policy helpers may exist inside features to drive visibility and ergonomics, but API authorization remains authoritative. Complex screens should be composed from feature-owned screen entrypoints and explicit domain sections, while generic table primitives may live in `ui` and business columns, actions, filters, and sort rules stay in features. Navigable screen state with sharing or restore value, such as filters, sorting, pagination, and active tabs, should live in the URL, while ephemeral interaction state stays local.
