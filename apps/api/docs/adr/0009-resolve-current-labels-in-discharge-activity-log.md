# Resolve current labels in the Discharge Activity Log

Discharge Activity Log events will retain identifiers, but not copied labels, for durable referenced entities such as Docks and acting Users. Consultation resolves their current labels and identities so corrections remain visible across older Discharges, consistently with other dynamic views; deactivation does not remove an actor, immutable Report Snapshots remain the boundary for historically frozen labels, and event payloads still preserve the actual business values changed by the event.
